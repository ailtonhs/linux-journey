# Aula 1 - Fundamentos

## Comandos
mkdir -cria pasta

cd nome-da-pasta -> entra na pasta

cd .. -> volta uma pasta

ls -> lista arquivos

cd -> entra em pasta

pwd -> onde estou


touch -> cria arquivo

### O que pratiquei
- criei pastas
- naveguei entre diretórios
- listei arquivos


#### Onde errei
- tentei ir direto de uma pasta para outra

#### O que aprendi
- preciso voltar uma pasta antes
